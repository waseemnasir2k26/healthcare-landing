# healthcare-landing (MediConnect)

Bilingual (French / English) landing page for a digital-health platform called MediConnect: services, practitioner profiles and an appointment call to action. Single-page React app with sample content.

Live: https://healthcare-landing-murex.vercel.app

## Stack

React, Vite, Tailwind CSS. `vercel.json` and `netlify.toml` are included for SPA routing.

## Run locally

```bash
npm install
npm run dev
npm run build
```

Demo built by SkynetLabs.
